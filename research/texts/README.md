# Searchable paper text

The first five text files come from the v3 project's `_reference/papers`
directory. Their legacy single-byte encoding was converted to UTF-8 using
Latin-1 (equivalent to Windows-1252 for all bytes present in these files), so
GitHub and code-search tools can read them. Existing mathematical-symbol loss
or extraction defects were not repaired or independently checked.
They provide searchable, code-review-friendly versions of the SToE
foundation, autoinjection, cognitive-architecture, architectural-gap, and
three-laws papers. See the original [PDF corpus](../corpus) for document layout,
figures, and formatting; these text versions were not newly OCR-verified.

`06_memory_is_connection_stoe_instruments_and_mcl.txt` was extracted directly
from the 14-page author-supplied PDF on 2026-09-01. It retains PDF page markers
for navigation. The PDF remains authoritative for its equations, tables,
Figure 1, and layout.

They are research claims and architectural proposals, not established
scientific conclusions. Read the experiment reports and limitations alongside
them.
